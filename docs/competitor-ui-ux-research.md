## 1️⃣ Co-Star — Мінімалістичний підхід

### Ключові особливості:
- **Чорний фон + білий текст** — драматичний, містичний вайб
- **Одна фіча = одна сторінка** — не перевантажує
- **Push-notifications** — щоденні прогнози як месенджер
- **Streak система** — геймифікація (читаєш щодня → отримуєш бейдж)
- **Соціальна фіча** — порівняння з друзями

### UI Patterns:

#### Місячні прогнози (Co-Star style):
```
┌─────────────────────────────────┐
│ 📅 БЕРЕЗЕНЬ 2026                │
│                                 │
│ ТВІЙ МІСЯЦЬ ВЕНЕРИ ♀           │
│                                 │
│ Ключові дати:                   │
│ • 5 березня — Меркурій ретро   │
│ • 15 березня — Повний місяць   │
│ • 25 березня — Нова кар'єра    │
│                                 │
│ [Детальніше →]                  │
└─────────────────────────────────┘
```

**Що копіювати:**
- ✅ Мінімалістичний дизайн
- ✅ Ключові дати виділені
- ✅ Короткі тези (не вали тексту)
- ✅ CTA кнопка для розширеного прогнозу

## 2️⃣ Astro.com — Професійний підхід

### Ключові особливості:
- **Багато даних** — таблиці, графіки, числа
- **SVG карти** — традиційні астрологічні символи
- **Експортні функції** — PDF, Print
- **Багато house систем** — Placidus, Koch, Equal і т.д.

## 3️⃣ Cafe Astrology — Content-first підхід

### Ключові особливості:
- **Довгі статті** — SEO-оптимізовані (2000+ слів)
- **Внутрішнє посилання** — "Читай також", "Дізнайся більше"
- **Безкоштовні калькулятори** — lead magnets
- **Рекламний** — багато AdSense

### UI Patterns:

#### Електіви (Cafe Astrology style):
```
═══════════════════════════════════════════════════════
🗓️ КОЛИ ОДРУЖУВАТИСЬ У 2026?
═══════════════════════════════════════════════════════

Найкращі дати для весілля (на основі Місяця):

✅ ВИСОКО СПРИЯТЛИВІ ДАТИ:
• 12 березня 2026 (П'ятниця) — Венера в Тельці
• 5 червня 2026 (П'ятниця) — Повний місяць у Стрільці
• 18 вересня 2026 (П'ятниця) — Венера тригон Юпітер

⚠️ УНИКАТИ:
• 10-25 березня — Меркурій ретро (контракти!)
• 3 квітня — Затемнення (непередбачувані зміни)

📖 Читай також:
→ Як вибрати дату для бізнесу
→ Місячні фази для весіль
→ Синастрія: сумісність партнерів

[Розрахувати персональну дату →]
```

**Що копіювати:**
- ✅ Конкретні дати з поясненням
- ✅ Градація: високо сприятливі vs уникати
- ✅ Cross-linking до інших фіч
- ⚠️ НЕ копіювати: занадто багато реклами

### Кольорова палітра (рекомендації):

**Варіант 1: Мінімалістичний (Co-Star style)**
- Primary: `#000000` (чорний)
- Secondary: `#FFFFFF` (білий)
- Accent: `#6366F1` (індиго) — для CTA кнопок
- Warning: `#F59E0B` (янтарний)
- Success: `#10B981` (зелений)

**Варіант 2: Містичний (Sanctuary style)**
- Primary: `#1E1B4B` (темно-синій)
- Secondary: `#F3E8FF` (лавандовий)
- Accent: `#A78BFA` (фіолетовий)
- Warning: `#FBBF24` (золотий)
- Success: `#34D399` (м'ятний)

**Рекомендація:** Почати з Варіант 2 (містичний) — більше підходить для астрологічної тематики + відрізняє від Co-Star.

---

### Типографіка:

**Заголовки:**
- Font: `Inter` або `Manrope` (сучасний sans-serif)
- Weight: 600-700 (semibold/bold)
- Size: 24-32px (h1), 18-24px (h2)

**Основний текст:**
- Font: `Inter` або `IBM Plex Sans`
- Weight: 400 (regular)
- Size: 16px (body), 14px (secondary)
- Line height: 1.6

**Акценти (цитати астролога):**
- Font: `Playfair Display` (serif для емоційності)
- Weight: 400-500 (italic)
- Size: 18px

---

### Іконографія:

**Астрологічні символи:**
- Використовувати Unicode символи: ☉ ☽ ☿ ♀ ♂ ♃ ♄ ♅ ♆ ♇
- Альтернатива: SVG іконки (більш красиві, можна анімувати)

**Емодзі для емоційного тону:**
- Позитив: ✨ 💚 🌟 💫
- Попередження: ⚠️ 🔴 ⚡
- Нейтральне: 🔵 🌙 🪐

## 📱 Респонсивність

### Пріоритети платформ:

1. **Mobile (320-768px)** — 70% користувачів
   - Вертикальний scroll
   - Картки з padding 16-24px
   - CTA кнопки на всю ширину

2. **Tablet (768-1024px)** — 15% користувачів
   - 2-колонкова сітка
   - Sidebar з навігацією

3. **Desktop (1024px+)** — 15% користувачів
   - 3-колонкова сітка (sidebar + content + widgets)
   - Більше інформації на екрані
